# 中转球

屏幕已经挤满的时候，把文件先放到悬浮球里，再用的时候拖进网页。

适合这种场景：浏览器开着 ChatGPT、Claude 或其他上传框，访达、文稿、桌面叠在一起，没法把文件直接拖进网页。中转球停在所有窗口上面，先接住文件，腾出手整理窗口后，再拖进网页。

拖进去的是副本。关掉悬浮球只会清空中转区，不会删除你原来的文件。

## 界面

菜单栏是一枚同心圆。关闭时中心是亮灰色，开启时中心是亮淡紫色。

| 关闭 | 开启 |
| --- | --- |
| ![关闭](docs/screenshots/menu-off.png) | ![开启](docs/screenshots/menu-on.png) |

开启后，屏幕上出现毛玻璃悬浮球。数字是当前暂存的文件数。

![悬浮球](docs/screenshots/ball.png)

点击悬浮球展开中转区。按住某一项，拖进浏览器的上传区域；也可以按住底部，一次拖出全部。截屏和普通文件之间有一条横线。截屏那一行的下载图标可以把图片一键存进你指定的文件夹。

![中转区](docs/screenshots/shelf.png)

## 使用

1. 打开 `中转球v2.app`。它只出现在菜单栏，没有程序坞图标。打开后悬浮球会直接出现，拖动球体可以换位置。
2. 把文件或文件夹拖进悬浮球。
3. 需要交给网页时，点击悬浮球，按住文件拖进 ChatGPT 等页面的输入框或上传区。
4. 按 Option+R（可在右键菜单里改）框选屏幕区域，按 Esc 取消。截图会自动放进中转球，排在普通文件上面，中间用横线隔开。点截图右侧的保存图标，即可存到指定文件夹；第一次会先让你选文件夹。
5. 点击悬浮球和列表以外的地方，列表会收起，文件仍留在球里。
6. 再点一次菜单栏图标，悬浮球消失，中转副本被清空。之后再点一次，悬浮球重新出现。

右键菜单栏图标可以调整：

- **悬浮球大小**：小、中、大
- **透明程度**：较透、标准、较实
- **截屏快捷键**：默认 Option+R
- **截屏保存到**：一键保存截图的目标文件夹
- **退出中转球**

按住 Option 再点击菜单栏图标，也会退出。

## 构建

需要 macOS 13 或更高版本，以及 Xcode 命令行工具。

```bash
cd 中转球
./build.sh
open ../中转球v2.app
```

`build.sh` 会编译菜单栏应用、做一次文件复制与清空的自测，并在上一级目录生成 `中转球v2.app`。

## 说明

- 放进悬浮球的是复制到临时目录的副本，拖出时也是复制，原文件留在原地。
- 关闭开关、退出应用，或下次启动时，都会清掉这些副本。
- 从网页或其他应用拖出的图片，如果没有文件路径，会存成 PNG 再供拖出。
- 框选截屏需要系统允许「中转球v2」录制屏幕。允许后如果这一次没有放进悬浮球，完全退出并重新打开再试。悬浮球会留在画面里，框到它就会出现在截图中。截图和拖入的文件一样，只是中转副本。截屏失败时，悬浮球上会短暂显示原因。
